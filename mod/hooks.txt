// Patches into ZERO Sievert's own code, applied by tools/utmt/build.csx to a copy of the original data.win.
// Format: '### findreplace|prepend|append <code entry name>', then the body, ended by <<<END.
//   findreplace: <<<FIND (exact decompiled text) ... <<<REPLACE ... ; the build fails if the FIND text is gone.
//   After a game update run tools/decompile.sh: tools/check_hooks.py lists the hooks that no longer match.
// Lines outside the ### blocks (like these) are ignored by the build.
// 'WORKAROUND (no source access)' marks a patch that only exists because the mod can't change the game's
// source; with the source most of them become a few lines in the right place.
// Never 'append' to a gml_GlobalScript_* entry: the code would land outside the function.
