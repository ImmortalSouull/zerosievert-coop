<summary><b>English</b></summary>

An unofficial co-op mod for ZERO Sievert (Steam, game version 1.4.13, build 26535665).
Made with AI (Claude). No game files are distributed: the installer patches your own copy of the game.

A small update for the game hotfix of 9 November 2026: the Steam update replaced the game's `data.win`, which
removed the mod, and the v2.0.0 installer refuses the new game build. v2.0.1 is the same mod built for the new
build. It can play with v2.0.0 (same protocol), but a v2.0.0 install no longer works on the updated game, so
everybody just installs v2.0.1.

## Fixed (compared to v2.0.0)
- Works with the game hotfix (Steam build 26535665).
- Weather: a guest could see their own weather in a raid (e.g. fog while the host had sun) until the next game
  hour. The raid owner now repeats the weather every 5 seconds.
- Installer: after a game update the backup kept the old game file, and `uninstall.bat` would have brought it back.
  The backup is now refreshed from the updated game.

## Installation
1. Close the game. ZERO Sievert 1.4.13 (Steam build 26535665) is required — update the game in Steam.
2. Download `ZS-Coop-v2.0.1.zip` below, unpack it anywhere and run `install.bat`.
   The installer finds the game by itself, makes a backup (`coop_backup` folder) and patches your own
   copy of the game. It also installs over an older version of the mod.
3. Uninstall: `uninstall.bat`, or Steam → Properties → "Verify integrity of game files".
4. In game: main menu → "Co-op" (or F7). Everybody must use the same mod version.

## Known bugs
- Over Steam, more than 2 players at once, host migration and voice chat were checked by the automated tests only
  (they connect the players by IP on one PC). If something goes wrong, send the logs ("Collect logs" in F7).
- The Epic Games Store version of the game is not supported: the mod is made for the Steam version.
- The translations other than Russian and English were made with AI: if something reads oddly, tell us and
  we'll fix it.
- Translation mods that replace the game's language files may show enemy callouts as keys
  (`npc.bark.bandit.reload_1`): those files lack the new AI's lines. "Verify integrity of game files" in Steam and
  reinstalling the mod help.
- An enemy outside a guest's screen may open fire on the guest at once. For the host the new game waits until
  the enemy is on their screen; for guests this rule can't be changed (it is in a part of the game's code the
  mod can't recompile).
- Visits show the friend's modules only (furniture, benches); traders, stash and quests stay your own.
- The radio exists only with this mod: playing without the mod, the game takes it out of the inventory and the
  stash (the save itself stays fine).

Неофициальный кооп-мод для ZERO Sievert (Steam, версия игры 1.4.13, сборка 26535665).
Сделан с помощью ИИ (Claude). Файлы игры не распространяются: установщик патчит вашу копию игры.

Небольшое обновление под хотфикс игры от 9 ноября 2026: обновление Steam заменило `data.win` игры, мод из-за
этого пропал, а установщик v2.0.0 новую сборку игры не принимает. v2.0.1 — тот же мод, собранный под новую сборку.
С v2.0.0 он совместим (тот же протокол), но v2.0.0 на обновлённой игре уже не ставится, так что всем просто
ставить v2.0.1.

## Исправлено (относительно v2.0.0)
- Работает с хотфиксом игры (сборка Steam 26535665).
- Погода: у гостя в рейде могла быть своя погода (например, туман, а у хоста солнце) до следующего игрового часа.
  Теперь владелец рейда повторяет погоду каждые 5 секунд.
- Установщик: после обновления игры в резервной копии оставался старый файл игры, и `uninstall.bat` вернул бы его.
  Теперь копия обновляется из обновлённой игры.

## Установка
1. Закройте игру. Нужна ZERO Sievert 1.4.13 (сборка Steam 26535665) — обновите игру в Steam.
2. Скачайте `ZS-Coop-v2.0.1.zip` ниже, распакуйте куда угодно и запустите `install.bat`.
   Установщик сам находит игру, делает резервную копию (папка `coop_backup`) и патчит вашу копию игры. Ставится и
   поверх старой версии мода.
3. Удаление: `uninstall.bat` или Steam → Свойства → «Проверить целостность файлов игры».
4. В игре: главное меню → «Кооп» (или F7). У всех должна быть одна версия мода.

## Известные баги
- Через Steam больше 2 игроков сразу, смена хоста и голосовой чат проверены только автотестами (они соединяют игроков
  по IP на одном ПК). Если что-то пойдёт не так — пришлите логи («Собрать логи» в F7).
- Версия игры из Epic Games Store не поддерживается: мод сделан для версии Steam.
- Переводы, кроме русского и английского, сделаны ИИ: если что-то звучит странно — напишите, исправим.
- Моды-переводы, заменяющие языковые файлы игры, могут показывать реплики врагов ключами
  (`npc.bark.bandit.reload_1`): в этих файлах нет строк нового ИИ. Помогают «Проверить целостность файлов игры» в
  Steam и переустановка мода.
- Враг за пределами экрана гостя может сразу открыть по нему огонь. Для хоста новая игра ждёт, пока враг окажется на
  его экране; для гостей это правило изменить нельзя (оно в части кода игры, которую мод не может перекомпилировать).
- Визиты показывают только модули друга (мебель, верстаки); торговцы, склад и задания остаются вашими.
- Рация есть только с этим модом: если играть без мода, игра уберёт её из инвентаря и склада (само сохранение не
  портится).

Nieoficjalny mod co-op do ZERO Sievert (Steam, wersja gry 1.4.13, build 26535665).
Zrobiony z pomocą SI (Claude). Pliki gry nie są rozpowszechniane: instalator łata twoją kopię gry.

Mała aktualizacja pod hotfix gry z 9 listopada 2026: aktualizacja Steam podmieniła `data.win` gry, przez co mod
zniknął, a instalator v2.0.0 nie przyjmuje nowego buildu gry. v2.0.1 to ten sam mod zbudowany pod nowy build.
Jest zgodny z v2.0.0 (ten sam protokół), ale v2.0.0 nie da się już zainstalować na zaktualizowanej grze, więc
wszyscy po prostu instalują v2.0.1.

## Naprawione (względem v2.0.0)
- Działa z hotfixem gry (build Steam 26535665).
- Pogoda: gość w rajdzie mógł widzieć własną pogodę (np. mgłę, gdy u hosta było słońce) do następnej godziny w grze.
  Teraz właściciel rajdu powtarza pogodę co 5 sekund.
- Instalator: po aktualizacji gry kopia zapasowa trzymała stary plik gry i `uninstall.bat` by go przywrócił.
  Teraz kopia jest odświeżana z zaktualizowanej gry.

## Instalacja
1. Zamknij grę. Wymagana ZERO Sievert 1.4.13 (build Steam 26535665) — zaktualizuj grę na Steam.
2. Pobierz `ZS-Coop-v2.0.1.zip` poniżej, rozpakuj gdziekolwiek i uruchom `install.bat`.
   Instalator sam znajduje grę, robi kopię zapasową (folder `coop_backup`) i łata twoją kopię gry. Instaluje się
   także na starszą wersję moda.
3. Odinstalowanie: `uninstall.bat` albo Steam → Właściwości → „Zweryfikuj spójność plików gry”.
4. W grze: menu główne → „Co-op” (albo F7). Wszyscy muszą mieć tę samą wersję moda.

## Znane błędy
- Przez Steam więcej niż 2 graczy naraz, zmiana hosta i czat głosowy były sprawdzane tylko testami automatycznymi
  (łączą graczy przez IP na jednym PC). Jeśli coś pójdzie nie tak, wyślij logi („Zbierz logi” w F7).
- Wersja gry z Epic Games Store nie jest obsługiwana: mod jest zrobiony dla wersji Steam.
- Tłumaczenia inne niż rosyjskie i angielskie zrobiła SI: jeśli coś brzmi dziwnie, daj znać, poprawimy.
- Mody tłumaczeń, które podmieniają pliki językowe gry, mogą pokazywać okrzyki wrogów jako klucze
  (`npc.bark.bandit.reload_1`): w tych plikach brak linii nowej SI. Pomaga „Zweryfikuj spójność plików gry” na Steam
  i ponowna instalacja moda.
- Wróg poza ekranem gościa może od razu otworzyć do niego ogień. U hosta nowa gra czeka, aż wróg będzie na jego
  ekranie; u gości tej zasady nie da się zmienić (jest w części kodu gry, której mod nie może przekompilować).
- Wizyty pokazują tylko moduły znajomego (meble, warsztaty); handlarze, magazyn i zadania zostają twoje.
- Radio istnieje tylko z tym modem: grając bez moda gra usunie je z ekwipunku i magazynu (sam zapis pozostaje
  w porządku).
