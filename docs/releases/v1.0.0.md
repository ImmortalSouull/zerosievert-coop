# ZERO Sievert CO-OP v1.0.0 — кооператив до 4 игроков / Co-op for up to 4 players

**Русский** · [English](#english)

Неофициальный мод на кооператив для ZERO Sievert (Steam, версия игры 1.3.3, build 25269476).
Сделан с помощью ИИ (Claude). Файлы игры не распространяются: установщик патчит вашу копию игры.

**Несовместим с v0.4.x и ниже** — обновитесь все (мод сам откажет в подключении и скажет почему).
`install.bat` ставится поверх старой версии.

## Новое
- **До 4 игроков.** Хост приглашает до трёх друзей через Steam (или по IP). Каждый видит всех: ники,
  HP, анимации, фонари, метки на карте КПК разными цветами.
- **Кнопка «Кооператив»** в главном меню и в меню паузы (F7 тоже работает).
- **Метки:** средняя кнопка мыши (на геймпаде — нажатие правого стика) ставит метку «туда» для всех.
- **Передача предметов:** подойдите к напарнику, нажмите X и выберите предмет — он окажется в мешке
  у его ног.
- **Если хост эвакуировался,** а остальные остались, мир рейда не распадается: его подхватывает
  следующий игрок, враги и лут остаются общими.
- **Переподключение:** при обрыве связи мод сам переподключается и возвращает вас в тот же рейд.
- **Надёжная доставка при игре по IP:** раньше важные события (лут, двери, ранения) могли теряться при
  плохом интернете — теперь они доходят гарантированно и по порядку.
- **Баланс под группу** (вкладка «Кооператив» в настройках сложности): дополнительные враги и
  здоровье врагов за каждого игрока сверх одного.
- **Геймпад** в панели кооператива, в меню поднятия и передачи предметов.
- **Проверка обновлений:** мод сообщит в меню, если вышла новая версия.
- Попадание по напарнику видно (он мигает, как ваш персонаж при попадании).
- Самопроверка мира: раз в 30 секунд мод сверяет список врагов у всех игроков и сам исправляет
  расхождения.

## Исправлено (относительно v0.4.0)
- Игра гостя падала, когда хост уходил из рейда, если у какого-то врага ещё не было названия
  состояния (`State "" unhandled`).
- При обновлении мода поверх старой версии новые пункты меню и переводы не устанавливались
  (установщик теперь каждый раз начинает с оригинальных файлов).
- Сверка карт могла ложно сообщать о различии, если в момент проверки появлялся труп.
- При большом пинге предмет, взятый из ящика, который открыт у обоих, мог вернуться обратно
  (дублирование лута).
- При большом пинге игра могла упасть, если состояние напарника приходило раньше его снаряжения.
- Метка «Новое» в главном меню игры съезжала на соседний пункт (из-за новой кнопки «Кооператив»).

## Проверено
Автоматические тесты на 2, 3 и 4 окнах игры: все карты (лес, лагерь, промзона, болото, ТЦ, Заков,
ЧАЭС), ранения/поднятие, общий лут, вход в идущий рейд (в том числе в рейд, начатый хостом в одиночку),
уход хоста и передача мира, обрыв связи на 20 секунд, плохая сеть (задержка 120 мс, 3% потерь),
21-минутная сессия на 4 игроков без ошибок и утечек памяти. Установщик проверен на обновлении поверх
старой версии и при повторной установке.

## Установка
1. Закройте игру. Нужна ZERO Sievert 1.3.3 (Steam build 25269476).
2. Скачайте `ZS-Coop-v1.0.0.zip` ниже, распакуйте в любую папку и запустите `install.bat`.
   Установщик сам найдёт игру, сделает резервную копию (папка `coop_backup`) и применит патч
   к вашей копии игры. Поверх старой версии мода тоже ставится.
3. Удаление: `uninstall.bat` или Steam → Свойства → «Проверить целостность файлов».
4. В игре: главное меню → «Кооператив». Версии мода у всех игроков должны совпадать.

## Известные баги
- Если хост полностью вышел из игры, сессия заканчивается: остальные доигрывают рейд каждый сам.
- Через Steam одновременная игра 3–4 человек проверена только на уровне кода — в автотестах игроки
  соединяются по IP. Если что-то не так — пришлите `coop_solo.log`.
- Не проверен запуск игры прямо из приглашения Steam, когда игра у друга закрыта.

## English

An unofficial co-op mod for ZERO Sievert (Steam, game version 1.3.3, build 25269476).
Made with AI (Claude). No game files are distributed: the installer patches your own copy of the game.

**Not compatible with v0.4.x and older** — everybody must update (the mod refuses the connection itself and
tells why). `install.bat` installs over the old version.

### New
- **Up to 4 players.** The host invites up to three friends via Steam (or by IP). Everybody sees everybody:
  names, HP, animations, flashlights, coloured markers on the PDA map.
- **A "Co-op" button** in the main menu and in the pause menu (F7 still works).
- **Ping markers:** the middle mouse button (gamepad: right stick click) marks a spot for everybody.
- **Giving items:** stand next to a teammate, press X and pick an item — it appears in a bag at their feet.
- **If the host extracts** while the others stay, the raid's world doesn't fall apart: the next player takes
  it over, enemies and loot stay shared.
- **Reconnect:** after a connection drop the mod reconnects by itself and puts you back into the same raid.
- **Reliable delivery when playing by IP:** important events (loot, doors, downs) could be lost on a bad
  connection before — now they always arrive, in order.
- **Group balance** (the "Co-op" tab of the difficulty settings): extra enemies and enemy health for every
  player beyond the first.
- **Gamepad** in the co-op panel, in the revive menu and the give menu.
- **Update check:** the mod tells you in the menu when a new version is out.
- A hit on a teammate is visible (they flash like your own character when hit).
- World self-check: every 30 seconds the mod compares the enemy list of all players and repairs differences.

### Fixed (compared to v0.4.0)
- The guest's game crashed when the host left the raid if an enemy had no state name yet
  (`State "" unhandled`).
- Updating the mod over an older version didn't install new menu entries and translations (the installer
  now starts from the original files every time).
- The map check could report a false difference when a corpse appeared at the moment of the check.
- With high ping, an item taken from a container both players had open could come back (loot duplication).
- With high ping the game could crash when a teammate's state arrived before their loadout.
- The game's "New" tag in the main menu moved to the wrong entry (because of the new "Co-op" button).

### Tested
Automated tests on 2, 3 and 4 game windows: every map (forest, camp, industrial area, swamp, mall, Zakov,
CNPP), down/revive, shared loot, joining a raid in progress (including one the host started alone), the
host leaving and the world handover, a 20-second connection drop, a bad network (120 ms latency, 3% loss),
a 21-minute 4-player session without errors or memory leaks. The installer was checked updating an older
version and installing twice.

### Installation
1. Close the game. ZERO Sievert 1.3.3 (Steam build 25269476) is required.
2. Download `ZS-Coop-v1.0.0.zip` below, unpack it anywhere and run `install.bat`.
   The installer finds the game by itself, makes a backup (`coop_backup` folder) and patches your own
   copy of the game. It also installs over an older version of the mod.
3. Uninstall: `uninstall.bat`, or Steam → Properties → "Verify integrity of game files".
4. In game: main menu → "Co-op". Everybody must use the same mod version.

### Known bugs
- If the host quits the game completely, the session ends: everyone finishes the raid on their own.
- Over Steam, 3–4 players at once were checked only at the code level — the automated tests connect the
  players by IP. If something goes wrong, send `coop_solo.log`.
- Launching the game directly from a Steam invite while the friend's game is closed is untested.
